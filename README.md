# Continuum Arcadia Amethyst — Bespoke Coachbuild Showcase & Atelier

A high-fidelity React + TypeScript web application for the **Continuum Arcadia Amethyst** hyper-luxury coachbuild automotive commission.

## Overview

Commission No. 01 of 01. The Continuum Arcadia Amethyst combines aerospace-grade graphene monocoque architecture, an extraordinary 3,000 HP twin-turbo V12 hybrid powertrain, predictive Active-Morph hydraulic suspension, and an exclusive horological pairing with Patek Philippe.

## Key Features

1. **Cinema Reel (4K)**: Fullscreen cinematic presentation video reel with ambient audio controls, play/pause, and telemetry HUD indicators.
2. **Curated Galleria**: 34 high-resolution masterwork captures across exterior dihedral gullwing doors, environments (coastal villa, mountain stream, midnight city, private vault), interior sanctuary, powertrain, and horology with interactive lightbox.
3. **Bespoke Atelier Configurator**: Interactive coachbuild configurator allowing real-time customization of exterior finishes (Amethyst Deep Velvet, Continuum Morph Duotone, Arcadia Silver, Midnight Shadow), illuminated crystal Spirit of Ecstasy, rear sovereign club seats or couch sofa conversion, luggage suite, and horology pairing with unique commission code generation.
4. **Engineering Anatomy & Cutaway**: Interactive hotspots positioned on the technical blueprint cutaway (`19. Anatomy.jpg`), plus dual engine inspection toggling between the twin-turbo V12 block and solid-state electric hybrid components.
5. **Cockpit & Starlight Sky-Lounge**: Dashboard explorer featuring open-pore Santos Palisander wood veneer, dual physical tourbillon chronometers, interactive drive mode dynamics (Arcadia Whisper, Sovereign Comfort, Continuum Hyper 3000 HP, Alpine Grand Tour), ambient lighting color controller, and electrochromic starlight opacity slider.
6. **Horology Suite (Patek Philippe pour Continuum)**: Live ticking mechanical clock complication synced with real-time, minute repeater tourbillon details, presentation casket, and titanium key fob with pulsating amethyst light beacon.
7. **Official Commission Dossier & Docket**: Printable technical specification document certifying the build allocation.
8. **Private Client Commission Inquiry**: Encrypted inquiry modal for allocation acquisition and custom treadplate engraving.

## Tech Stack

- **Framework**: React 19 (TypeScript)
- **Bundler**: Vite 6
- **Styling**: Tailwind CSS v4
- **Icons**: Lucide React
- **Audio**: Web Audio API Ambient Atmosphere Synthesizer
